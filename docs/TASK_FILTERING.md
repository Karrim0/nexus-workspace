# Task filtering and sorting

The My Tasks board now supports shareable URL-based filters.

## Filters

Users can narrow assigned tasks by:

- task title
- priority
- workflow status

## Sorting

Tasks can be ordered by:

- due date, soonest first
- due date, latest first
- priority
- title

## Behavior

Filtering is applied only to the current user's assigned tasks.

The board keeps its four workflow columns while sorting the cards inside each visible column.
