# Task project and due-date filtering

The My Tasks view now supports two additional filters that make larger workspaces easier to scan.

## Project filter

Users can narrow assigned tasks to a single project while keeping the existing Kanban workflow columns.

## Due-date filter

Supported due views:

- overdue
- due today
- upcoming
- no due date
- any due date

Completed tasks are excluded from the overdue result set.

## Existing filters

The new controls work alongside:

- task title search
- priority
- workflow status
- due-date/title/priority sorting

All filter state remains in URL query parameters.
